# 电子标签异常处置 · PDA 预览

Vue2 H5，320×533。在线预览：

**https://bigsenz0007-tygi.github.io/etag-exception-pda/**

本地：

```bash
npm install
npm run serve
```

打开 `http://localhost:5180/`。点击「扫一扫」用灰色小字演示码走流程。

| 物资码 | 扫后 |
| --- | --- |
| `CSL22010533608938` | 损坏 / 脱落 / 绑错 |
| `WZUNREG001` | 未注册 |
| `WZLOW001` | 电量低于 5% |
| `WZOK001` | 状态正常 |
| `WZNONE001` | 物资不存在 |
